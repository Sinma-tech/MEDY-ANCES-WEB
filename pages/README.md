
# MEDY ANCES - Sitio Web Informativo

## Descripción del proyecto

Desarrollo de un sitio web informativo para la microempresa
MEDY ANCES, dedicada a la medicina ancestral, productos
naturales, servicios tradicionales y orientación espiritual.

El proyecto se desarrolla como parte de la asignatura
Fundamentos de Sistemas Web de la Universidad de las
Fuerzas Armadas ESPE.

## Objetivo

Diseñar e implementar un sitio web informativo que permita
presentar la identidad, historia, servicios, productos,
equipo de trabajo y datos de contacto de MEDY ANCES.

## Tecnologías utilizadas

- HTML5
- Visual Studio Code
- Git
- GitHub

El sitio web se desarrolla utilizando únicamente HTML,
sin CSS ni JavaScript.

## Estructura del proyecto

MEDY-ANCES-WEB/
- index.html - Página principal
- nosotros.html - Información institucional
- servicios.html - Servicios tradicionales
- productos.html - Catálogo de productos
- equipo.html - Equipo de trabajo
- contacto.html - Información de contacto
- imagenes/ - Recursos gráficos
- README.md - Documentación del proyecto

## Organización de ramas Git

- main: versión final del sitio web.
- desarrollo: integración del trabajo de ambos programadores.
- pruebas: revisión y verificación del sitio.
- andrea: desarrollo de las páginas del programador 1.
- limber: desarrollo de las páginas del programador 2.

## Funcionalidades

- Navegación entre seis páginas HTML.
- Presentación de la microempresa.
- Información de historia, misión, visión y valores.
- Descripción de servicios tradicionales.
- Catálogo informativo de productos.
- Presentación del equipo de trabajo.
- Información de contacto.
- Incorporación de imágenes y tablas.

## Ejecución del proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo index.html en un navegador.
4. Navegar mediante los enlaces del menú principal.
